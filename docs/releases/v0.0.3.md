# AdaptiveLinearSolvers v0.0.3 发布说明

## 1. 发布范围

`0.0.3` 在 `0.0.2` 的数学规划和资格层之上，接入了实际 Krylov 执行后端、可应用预条件器算子、矩阵自由算子和块耦合算子。该版本仍处于试验期，不承诺稳定 API。

## 2. Krylov 执行与报告

通过 `Krylov.jl` 执行 CG（Conjugate Gradient，共轭梯度法）、MINRES（Minimum Residual，最小残量法）、GMRES（Generalized Minimal Residual，广义最小残量法）、FGMRES（Flexible Generalized Minimal Residual，柔性广义最小残量法）和 BiCGStab（Biconjugate Gradient Stabilized，稳定化双共轭梯度法）。

`IterationControl` 统一控制最大迭代数、墙钟时间、GMRES/FGMRES 重启和残差历史记录；`IterationReport` 返回收敛状态、迭代数、后端状态、耗时与残差历史。达到调用方迭代或时间预算时返回 `BudgetTerminated`，其他未收敛情形返回 `NumericalFailure`。

## 3. 预条件器接口

`PreconditionerContract.operator` 必须实现预条件器逆作用 $P^{-1}$。固定线性预条件器作为 Krylov 左预条件器 `M`；可变或非线性预条件器仅作为 FGMRES 的柔性右预条件器 `N`。CG 与 MINRES 在存在预条件器时还要求 Hermitian 正定证据。没有实际 `operator` 的非空预条件器契约不会被静默忽略，而是使相应路线不可执行。

## 4. 矩阵自由与块耦合

`MatrixFreeOperator(rows, cols, apply!)` 支持原位 $y=Ax$ 作用，不要求显式组装矩阵。直接分解路线会被拒绝，路由器在未锁定直接路线时自动选择合格 Krylov 方法。

`BlockLayout` 和 `BlockOperator` 以扁平 Krylov 向量保留字段块边界；子块可以是显式矩阵或矩阵自由算子。此能力为 Vlasov-Fokker-Planck 高阶矩与 Maxwell 场的全耦合离散、后续字段分裂与 Schur 补预条件器提供接口基础。

## 5. 验证记录

测试命令：

```powershell
julia --project=. -e 'using Pkg; Pkg.test()'
```

环境为 Julia `1.12.6`、Krylov `0.10.9`。结果为 `48/48` 测试通过，耗时约 `15.7 s`。

## 6. 未包含功能

- Jacobi、ILU（Incomplete LU，不完全 LU 分解）、代数多重网格和物理预条件器构造器。
- 伴随矩阵自由作用、矩形最小二乘、LSQR、LSMR。
- Schur 补、字段分裂和块三角预条件器。
- GPU、MPI、分布式向量、持久化历史与高级诊断遥测。
